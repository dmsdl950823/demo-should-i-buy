# Jev 구매 판단 MVP 점검 — 2026-09-22

이 평가는 [사전 등록한 20개 예시와 5개 반복](evaluation-cases.json)을 [로컬 Next API route](../app/api/decision/route.ts)에서 Vercel AI Gateway의 `typesafe-ai/jev`로 한 번씩 보낸 결과다. 입력 금액은 예시이며 실제 상품 가격이 아니다. 자동 재시도 없이 순서대로 실행했다. [요청별 결과](evaluation-results.json)에 choice, confidence, 세 선택지 확률을 기록했다. 키와 공급자 원문은 저장하지 않았다.

| 지표 | 결과 |
|---|---:|
| 호출 및 응답 계약 성공 | 25/25 |
| 사전 허용 선택지 일치 | 19/20 (유효 응답 기준도 19/20) |
| 반복 5쌍의 choice 동일 | 5/5 |
| 반복 confidence 차이 최댓값 | 0.04 |
| 반복 개별 확률 차이 최댓값 | 0.02 |

불일치는 S2 한 건이다. 고장 난 일상용 운동화를 매일 사용하고 필요도가 높지만, 예시 가격 40만원이 여유자금 30만원보다 클 때 사전 기준은 `WAIT`였다. Jev는 `BUY`를 선택했다(confidence 0.25, BUY 확률 0.50). 낮은 confidence와 경계적인 분포를 함께 봐야 한다. 이 사례를 보고 허용 기준을 사후 변경하지 않았다.

각 제품군의 기준 사례와 가격 상승·예산 감소 사례를 비교했을 때 BUY 확률이 증가한 쌍은 없었다. 예를 들어 노트북은 기준 N1에서 1.00, 가격 상승 N2에서 0.19, 예산 감소 N3에서 0.14였다. 다른 제품군의 정확한 수치는 요청별 JSON을 참조한다.

이 수치는 작은 주관적 예시에서 **미리 정한 기준과의 일치 및 반복 일관성**만 보여준다. 구매의 객관적 정답률, 구매 만족 확률, 모든 상품에서의 정확도, TypeSafe 직접 연결과 Gateway 경유의 품질 동등성을 뜻하지 않는다. 모델 가격·무료 제공 여부도 시간이 지나면 바뀔 수 있으므로 배포 전에 다시 확인해야 한다.
